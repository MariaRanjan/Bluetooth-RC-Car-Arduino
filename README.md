# Arduino Bluetooth Controlled Car

This project implements a Bluetooth-controlled robotic car using Arduino and L298N motor driver.

## 🔧 Components Used
- Arduino UNO
- L298N Motor Driver
- DC Motors
- HC-05 Bluetooth Module
- Robot Chassis
- Power Supply

## 🎮 Control Commands

| Command | Action |
|---------|--------|
| F       | Forward |
| B       | Backward |
| L       | Left |
| R       | Right |
| S       | Stop |

## 📌 Features
- Serial communication based control
- Real-time motor movement
- Simple and efficient logic
- Beginner-friendly embedded project

## 🧠 Learning Outcomes
- Embedded C/C++ programming
- Serial communication handling
- Motor driver interfacing
- Basic robotics control logic
